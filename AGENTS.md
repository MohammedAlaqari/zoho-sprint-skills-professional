# Project rules

- Never open, control, or launch a web browser for work in this repository. This includes OAuth sign-in and device authorization pages.
- Access Zoho only through the configured MCP connection. Do not use the Zoho web UI or call the Zoho API directly. If an MCP operation needs browser sign-in, direct API access, or a capability the connection does not expose, stop that operation and report the blocker.
- Local file inspection, code changes, and tests are allowed. Keep private MCP endpoints and credentials out of output and committed files.
